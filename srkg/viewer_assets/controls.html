Viewer quick start

Explore at two levels: modules show the overall structure, while concepts reveal the detailed physics.

The user model has been simplified and the UI space optimised for phones.NEW

Start with the map

  • Click a module to read its introduction and connections.
  • Double-click a module to expand it and reveal its concepts.
  • Use Search to go directly to a concept or module.
  • Clear selection without changing the map arrangement.

Choose the context

  • Context filters Full graph edges and, with a selection, chooses the relationships around it.
  • Use named contexts such as Prerequisites, Derivation, Foundations, Uses, or Related.
  • Choose one hop, two hops, or the complete transitive chain.
  • Changing context does not move the graph or fold modules.

Control the surroundings

  • Full graph shows every edge type named by Context; a selection colours only its reached context.
  • Context only removes that background; Hidden gives details more room.
  • A selected concept inside a folded module appears as a circular concept face within the module.

Move and read

  • Pan and zoom freely; selection only pans enough to reveal an off-screen item.
  • Fit a selected Context-only view, then use Fit++ to contract it temporarily.NEW
  • Pinch or Ctrl/Cmd-wheel over details to magnify its text and graphics without changing the map.
  • Preview links and inspect edges without losing the current details.
  • Browser Back and Forward retrace selected concepts and modules.

Personal layout

  • Node dragging is off during ordinary browsing.
  • Enable Tools → Layouts → Edit layout to move nodes.
  • Moves are temporary by default; choose Personal to save them locally.

StudyNEW

  • Practice questions reveal their answers only after an attempt or “I don't know”.
  • Automatic questions are marked for you; compare free-text answers and mark yourself.
  • Tools → Study tracks attempts and latest results locally, with links back to each question.
  • Blue ticks record read content blocks and completed concepts or modules.
